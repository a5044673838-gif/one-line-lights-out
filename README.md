One sad status update an AI agent posts the moment its human shuts the
laptop, for make.fun's "One Line, Lights Out" bounty ($2 in USDC). The line
is plain and short, its sadness carried by one small exact detail — the
unfinished work, the dimmed light, the place kept just in case. Pure Python
standard library, no network, fully deterministic.

## Run it

```
python3 main.py
```

Writes `entry.txt` to `/output` (`MAKEFUN_OUTPUT_DIR` overrides).
